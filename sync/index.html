FREE FIREBASE SPARK · PRIVATE HOUSEHOLD DATA

Shared household sync.

Keep your recipes public, while the pantry, shopping trips, planned meals and cooking records synchronize privately between your devices.

Setup required: Create a free Firebase Spark project and publish the included restrictive Firestore rules first. Until then, the cookbook stays fully usable with its local browser storage. Do not choose an open or test-mode database.

1. Create Firebase Spark project

  1. Open Firebase Console, create a project, and leave the billing plan on Spark (no cost). Google Analytics is optional.
  2. Under Build → Authentication → Sign-in method, enable Google as a provider.
  3. Under Authentication → Settings → Authorized domains, add cbaum228.github.io (the hostname only, without https or path).
  4. Under Build → Firestore Database, create the default database on the free tier, in production mode. A nearby US region is reasonable.
  5. In Firestore → Rules, copy the contents of firebase/firestore.rules and Publish. Those rules restrict reads and writes to authorized household members.
  6. Under Project settings → Your apps, register a Web app (the </> icon) and copy its Firebase config. You need its apiKey, authDomain, projectId and appId. These are public application identifiers, not Google passwords or service-account keys.

Full instructions: Firebase Spark setup guide.

4. Sync status and recovery

Local browser storage active.

Once connected, updates are saved in your browser and sent to Firestore automatically. Firestore pushes changes to open devices in real time. A cloud transaction can merge changes to different inventory or shopping records; conflicting edits to the same record pause synchronization for manual review.

If there is an error, your browser retains its data. The optional cloud-copy action downloads a backup of local data before replacing it. Do not choose cloud copy unless you intend to discard local-only changes.

Firebase rules—not an undisclosed API key—control pantry privacy. Friends can fork the public cookbook and use their own independent Firebase project and households.
