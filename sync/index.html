OPTIONAL PRIVATE SYNC

Shared household pantry.

Keep public recipes on GitHub and privately share your shopping list, pantry and cooking records through one restricted Google Drive JSON file.

Initial setup is required. This site does not have permission to your Google Drive until you configure your own Google Cloud project and explicitly sign in. Local data works without Google Drive. Google tokens are held only in the current page's memory, never committed to GitHub.

1. Google Cloud setup

Do this once for the cookbook's public website. You control the project and which Google accounts may connect.

  1. Open the Google Cloud Console, create/select a project and copy its numeric Project number.
  2. Enable Google Drive API and Google Picker API.
  3. Under Google Auth Platform, configure the OAuth consent screen. Choose External if appropriate; while in Testing, add both adults as test users. Request the https://www.googleapis.com/auth/drive.file scope.
  4. Create an OAuth Client ID → Web application. Add https://cbaum228.github.io as an Authorized JavaScript origin (no path). Copy the Client ID. Do not use or share a Client Secret.
  5. Create an API key for Picker. Restrict it to Google Picker API and Drive API; restrict HTTP referrers to https://cbaum228.github.io/* and https://docs.google.com/*, as required for the Google-hosted Picker frame.

Your OAuth Client ID, Picker API key and project number identify your application. They are not credentials granting access to private files; each adult still explicitly authorizes Google access and the individual file.

2. Save browser configuration

Configuration is saved only in this browser. On your spouse's device, use these same public application settings. No passwords, client secrets or account tokens should be pasted into these fields.

3. Connect the household file

Local-only mode

Open household JSON file in Google Drive

First device: Sign in, select Create new private pantry file, open its Drive link and share it with your spouse using Restricted → Editor. Keep it restricted to your intended Google accounts.

Second device: Sign in using the other authorized Google account, choose Choose existing / shared file, find family-recipes-household.json in the shared Drive view, and select it. Both devices then use the same restricted file.

What happens after connecting?

The cookbook checks Drive when a connected page is opened or refocused and approximately every 45 seconds while open. Local edits are saved immediately to the browser and synchronized after a short delay. If offline or authorization expires, local edits remain on the device until you reconnect.

Important limitations: Browser OAuth access tokens expire and cannot be silently refreshed without user interaction. After navigating to a new cookbook page you may need to use Sign in to Drive again. Simultaneous edits to the very same ingredient are flagged by the three-way merge, but Google Drive's whole-file update does not provide full database-style transactions. Avoid simultaneous edits to the same shopping item until we have tested this across both devices.

Backing up locally before first connection is recommended. The site asks before replacing a nonempty local pantry with the selected shared file and downloads a JSON copy.
