# Retired Google Drive design

The Google Drive JSON integration was superseded by [Firebase Spark private household sync](firebase-spark-setup.md).

The cookbook **does not load or execute the old Google Drive adapter**. Firebase provides private Google sign-in, Firestore Security Rules, real-time listeners, and transaction-based writes for two-person shopping and pantry edits, without requiring a paid Google Cloud project for normal Spark usage.

This file is retained to document the original design decision; follow the Firebase setup guide instead.
