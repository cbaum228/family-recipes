# Contributing recipes

Recipe data is public. Never commit private pantry backups, family medical details, login credentials or token files.

Create a new `_recipes/slug.md` using a complete recipe as a template. Keep ingredient names and shopping keys standardized, use grams and milliliters, and document substitutions.

State whether the recipe is `ready-to-test` or `tested`; historical incomplete recipes should remain `needs-reconstruction`. Preserve important cooking adjustments in the history section.

The recipe site exposes base quantities via Schema.org Recipe JSON-LD; MacroFactor may import the page URL, but users must verify the resulting matches and measure final cooked batch weight.
